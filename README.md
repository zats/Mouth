# Mouth

![Mouth icon](Mouth/Assets.xcassets/AppIcon.appiconset/512.png)

Mouth is a macOS menu bar app that watches local AI coding sessions and reads new assistant messages out loud.

[Download](https://github.com/zats/Mouth/releases/latest)

## Features

- Detects active Codex and Claude Code session files.
- Monitors session updates in near real time.
- Speaks new assistant messages with a delimiter sound.
- Lets you pause/resume or stop playback from the menu bar.
